Konfigurera Elprisdisplay

Anslut till displayen, välj WiFi och ställ in elområde, moms och eventuell MQTT-telemetri.

Slå på Bluetooth och använd Chrome på Android eller Chrome/Edge på datorn.

Lösenordet skickas direkt till displayen via Bluetooth.

25 % moms läggs på både verkliga priser och prognoser.

Telemetri skickas endast när WiFi ändå används.

Lämna tomt vid omkonfiguration för att behålla lagrat lösenord.
